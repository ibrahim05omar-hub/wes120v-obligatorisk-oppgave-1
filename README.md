# Wes120V-obligatorisk-oppgave-1

## Hva prosjektet er 
jeg har lagd ett vite prosjekt, som er om å lage en nettside.

## Node.js og Pnpm må være installert
Den skal kjøres og for at den skal kjøres/gå så må jeg ha installert node,js og pnpm på ubuntu terminal

## Hvordan avhengighetene installeres med pnpm install
for å kjøre en prosjektet må du laste ned avhengighetene som lastest in av å taste inn komadoen pnpm install.

## Hvordan utviklingsserveren startes med pnpm dev
for at serveren eller prosjektet skal starte taster jeg kommandoen pnpm dev, for å gå inn på nettsiden i nettleseren 

## Siden åpnes på adressen vite viser i terminalen
Serveren starter med å taste inn dev kommandoen pnpm, og da kommer det en link og den tar deg til nettsiden din og kan se hvordan nettleseren din ser ut

## Utvikling
Prosjektet bruker vite som utviklingsserver 

## Prosjetskruktur

Prosjekter består av en enjel index.html-fil som er entrypointet for nettsiden
